# TomatoTimer 发布版使用说明

TomatoTimer 是一款 Windows 桌面番茄钟软件，将专注计时、日程计划、每日日志和本地音乐整合在手绘手帐风格的界面中。

这份说明适用于从版本 Tag 对应的 Release 下载的发布包。使用发布版无需安装开发工具，也无需编译源码。

## 1. 下载与启动

1. 在项目仓库的 **Releases** 页面选择需要的版本；也可以从 **Tags** 找到对应版本，进入其 Release 页面。
2. 展开 **Assets（附件）**，下载作者上传的 Windows 发布包。页面自动生成的 `Source code (zip)` 和 `Source code (tar.gz)` 是源代码归档，不能直接作为桌面软件运行。
3. 将发布包完整解压到一个固定的文件夹。更新时建议使用新的文件夹，避免混入旧版文件。
4. 打开解压后的目录，双击 `TomatoTimer.exe`。请保留同目录的依赖文件和子文件夹，不要只单独复制 exe，也不要直接在压缩包内运行。

### 如何选择发布包

以对应版本的 Release 附件说明为准：

| 发布包类型 | 使用要求 |
| --- | --- |
| Windows x64 自包含版 | 适用于 x64 Windows，自带 .NET 运行时，解压后运行 |
| 框架依赖版 | 需要先安装与发布包架构匹配的 **.NET 10 Windows Desktop Runtime** |

如果启动时提示缺少 .NET，请从 [微软 .NET 10 下载页面](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)安装 **.NET Desktop Runtime 10.0** 对应架构的版本，再重新启动软件。Windows Desktop Runtime 包含 WPF 桌面应用所需组件。

## 2. 第一次使用

1. 在「专注计时」中点击「选择工作区」，或点击侧栏底部的工作区入口。选择或新建一个可写文件夹，例如 `D:\TomatoWorkspace\学习`。
2. 选择「休闲模式」，填写本次任务名称。
3. 设置专注时长，默认是 **25 分钟**，可以分别调整小时、分钟和秒。
4. 点击「开始专注」。过程中可以暂停、继续或提前结束。
5. 需要记录想法时，进入「每日日志」，选择日期并编辑，完成后点击「保存」。

工作区用来保存日志和专注记录。可以为学习、工作或不同项目选择不同文件夹；建议将工作区放在程序解压目录之外，方便以后更新软件。

## 3. 两种专注模式

### 休闲模式：随时开始一个任务

适合临时阅读、写作、学习或处理一件事。在计时页填写任务名称和时长，即可独立开始，不需要先创建日程计划。

### 日程模式：按顺序完成今天的计划

1. 进入「日历与计划」，选择今天。
2. 添加计划，为需要计时的计划启用「添加番茄钟」，填写时长并保存。
3. 返回「专注计时」，切换到「日程模式」。
4. 确认番茄钟之间的休息时间和铃声设置，然后开始。

软件会按当天计划的顺序执行未完成的番茄钟任务，显示当前位置与总进度，并在任务之间安排休息。普通待办和其他日期的计划不会进入今天的计时队列。

暂停不会跳过当前任务；手动结束会停止自动推进。计时页与日历页还可以查看计划时长分配，以及当前工作区今天的实际专注时间，暂停时间不计入实际专注。

## 4. 管理日历与计划

在「日历与计划」中点击日期，查看、添加或整理当天的计划。每项计划可以作为普通待办，也可以附带番茄钟。

- **未完成**：仍待处理的计划。
- **已完成**：已经完成的计划。
- **搁置**：暂时不做，放入搁置箱；之后可以恢复到今日日程，或独立执行。
- **放弃**：放入垃圾箱，当天仍可恢复；过期项目会在次日或后续启动时自动清理。

每日计划由应用统一保存，独立于工作区。切换工作区主要切换日志和专注记录。

## 5. 书写与回看日志

1. 进入「每日日志」，在日期时间线上选择一天，也可以使用日期选择框。
2. 打开当天日志，在编辑器中书写。即使当天没有专注记录，也可以单独写日志。
3. 使用工具栏设置标题、粗体、斜体、列表、引用和链接等格式，或切换到预览查看效果。
4. 点击「保存」，或在日志页按 `Ctrl+S` 保存。

日志以 Markdown 文件保存，可以用其他文本编辑器打开。通过历史日志、日期时间线和日历入口，可以回看过去的内容；计时记录与日志分别查看。

切换日期或离开编辑页面时，如果出现未保存提示，请按需要保存或放弃修改。如果检测到外部文件修改或出现恢复草稿，请根据提示确认要保留的内容。

## 6. 音乐与铃声

在「音乐与铃声」中点击「导入音频」，选择本地 MP3、WAV 等音频文件。导入后可以播放、暂停、切换曲目、调整进度和音量。具体格式能否播放取决于 Windows 的解码支持。

计时页可以分别选择开始铃声和结束铃声，并进行试听。音乐和铃声音量可在偏好设置中分别调整；铃声播放时背景音乐会让位，提醒结束后可按设置恢复。结束铃声最多播放 30 秒，也可以手动点击「停止铃声」。

音乐库保存的是原文件路径。从列表移除条目不会删除音频文件；文件被移动后，请使用「重新定位文件」更新路径。背景图片也采用路径引用，请保留原文件。

## 7. 悬浮时钟、托盘与外观

- **悬浮时钟**：在「偏好设置」中开启，可以拖动顶部移动，在小窗口里查看任务、暂停或继续，并返回主窗口。它与主窗口共享同一个计时任务。
- **系统托盘**：默认点击主窗口的关闭按钮后，软件会隐藏到托盘，计时和音乐继续运行。双击托盘图标恢复窗口，右键可以暂停或继续、停止铃声、退出软件。图标也可能位于任务栏的隐藏图标区域。
- **外观与习惯**：可以设置默认专注时长、背景颜色、背景图片及不透明度、动画时长，以及关闭窗口时是否保留在托盘。

完全退出请使用托盘菜单中的「退出」。如果当前番茄钟尚未结束，退出会将本次专注记为已中断，并显示确认提示。

## 8. 数据位置与备份

| 数据 | 保存位置 |
| --- | --- |
| 每日日志 | `<工作区>/Logs/yyyy-MM-dd/Daily.md` |
| 专注记录 | `<工作区>/Logs/yyyy-MM-dd/Sessions/HHmmss_<会话ID>.json` |
| 偏好设置、计划、音乐索引和恢复草稿 | 默认在 `%LOCALAPPDATA%/TomatoTimer/`，实际位置以「偏好设置 → 本地数据」显示为准 |

可以在「偏好设置 → 本地数据」中打开当前数据目录，或使用「修改位置」切换存储目录。修改这个位置不会搬动工作区的日志和专注记录。旧版本的 `%LOCALAPPDATA%/TomatoTimerPro/` 目录会兼容读取。

备份时先保存日志并退出软件，再复制以下内容：

1. 各个工作区文件夹。
2. 「偏好设置 → 本地数据」中显示的应用数据目录。
3. 引用的音频和背景图片原文件。如果修改过数据位置，也请保留默认目录中的 `storage-location.txt`，以便在同一台电脑上保留目录指向。

将备份迁移到另一台电脑时，原来的盘符和文件路径可能不同，需要重新选择工作区，并为音频、背景图片及应用数据目录设置有效路径。

## 9. 更新版本

1. 保存正在编辑的日志，结束当前任务，并从托盘菜单中「退出」旧版本。
2. 按上一节备份工作区和应用数据。
3. 从新版本 Tag 对应的 Release 下载发布包，完整解压到一个新文件夹。
4. 运行新目录中的 `TomatoTimer.exe`。在同一 Windows 用户下，只要应用数据目录和工作区仍可访问，新版本会继续读取已有数据。若该版本有额外迁移要求，以 Release 说明为准。
5. 确认日志、计划和设置正常后，再自行清理旧程序目录。若曾把工作区或应用数据放在旧程序目录内，请先迁出并确认备份。

如果提示已有另一个构建版本运行，请先从托盘退出旧实例，再启动新版。仅关闭主窗口可能仍会让旧版留在后台。

## 10. 常见问题

### 下载后找不到 TomatoTimer.exe

确认下载的是 Release 的应用附件，而不是自动生成的 Source code 源码包；也请检查是否已经完整解压。

### 提示缺少 .NET，或程序无法启动

先确认发布包架构与系统匹配。框架依赖版需要 **.NET 10 Windows Desktop Runtime**；安装其他版本的 .NET 或仅安装 ASP.NET Core Runtime，可能无法满足要求。自包含版需保留发布包中的所有文件。

### 点击关闭后，音乐或计时还在继续

这是默认的托盘运行行为。双击托盘图标恢复窗口；需要完全关闭时，在托盘右键菜单选择「退出」。

### 日程模式无法开始

确认选择的是今天，至少有一项未完成计划已启用番茄钟并保存了有效时长；普通待办、已完成计划和其他日期的计划不会加入今天的计时队列。

### 日志或记录看起来不见了

先确认当前工作区和日期是否正确。日志和专注记录按工作区保存；计划则独立于工作区。若文件夹曾移动，请重新选择实际工作区，并确认它包含原来的 `Logs` 目录。

### 音频导入后无法播放

确认原文件仍在原位置，必要时重新定位。若路径有效，尝试使用 MP3 或 WAV 文件，并确认系统能够播放该音频。

### 日志保存失败

检查工作区是否仍存在、磁盘是否有可用空间，以及当前用户是否有写入权限。外置磁盘断开或文件被其他程序占用时，请恢复可写状态后重试。
